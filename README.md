# SpeakPro English Coach

A small offline Java console chatbot for English conversation, vocabulary, grammar, writing, speaking prompts, and study planning.

## Run

Open a terminal in this folder and run:

```text
javac SpeakPro.java
java SpeakPro
```

Requires a Java Development Kit. No external libraries, API key, or internet connection are needed.

## Notes

- Use the numbered menu to choose an activity; enter `0` to exit.
- The chatbot uses fixed lessons and simple rules. It is not connected to an AI model and cannot listen to audio.
- Scores are lightweight practice estimates, not formal CEFR assessments.
- Progress is kept in memory for the current run only and is not saved between runs.
